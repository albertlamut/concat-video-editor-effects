## Installation / Instalación
Extract an individual ZIP from `dist/` into `~/.config/app.concat.editor/effects/`. Keep each custom.* folder directly inside effects.

Extrae un ZIP individual de `dist/` en `~/.config/app.concat.editor/effects/`. Cada carpeta custom.* debe quedar directamente dentro de effects.
